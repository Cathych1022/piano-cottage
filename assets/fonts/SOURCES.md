# Self-hosted cottage fonts

Downloaded from the official Google Fonts CSS API on 2026-11-15. Chinese fonts are subsetted by the API to the application's Chinese UI characters; system fallback fonts display other names and user-entered characters. The English file is the Latin subset. Font files are cached with the app for offline use.

- `cottage-playful.woff2`: [ZCOOL KuaiLe](https://github.com/google/fonts/tree/main/ofl/zcoolkuaile), used for playful Chinese headings and buttons.
- `cottage-text.woff2`: [LXGW WenKai TC](https://github.com/google/fonts/tree/main/ofl/lxgwwenkaitc), used for readable handwritten Chinese copy.
- `cottage-hand.woff2`: [Patrick Hand](https://github.com/google/fonts/tree/main/ofl/patrickhand), used for English copy and timer digits.

Each font's full SIL Open Font License is included alongside its file. Font outlines have not been edited.
